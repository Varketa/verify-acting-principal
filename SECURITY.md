# Security

This library decides whether a request to your API is accepted, so a flaw in it can let a forged, replayed or
misdirected request through. Please report one privately.

**Report a vulnerability through GitHub's private vulnerability reporting:** the "Report a vulnerability" button on
this repository's Security tab. Do not open a public issue for a vulnerability.

We respond on a best-effort basis. No response time is promised.

Include the library and version, the input (an assertion, request and key set if you can share them) and what the
verifier did against what SPEC.md says it must do.
